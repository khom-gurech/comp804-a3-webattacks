Task 3: HTML & CSS - Web Attacks

Name Web Attacks
SQL Injection

Image source: Wikimedia Commons

SQL injection occurs when untrusted input is incorporated into a database query in an unsafe way. An attacker may manipulate the query so that the database performs actions the application did not intend. A successful attack can expose, modify or delete information stored in the database.

More information about SQL Injection

Reference: OWASP Foundation - SQL Injection

Cross-Site Scripting (XSS)

Image source: Wikimedia Commons

Cross-Site Scripting occurs when untrusted content is treated as executable script in a user's web browser. The malicious script runs in the context of a trusted website and can act using the victim's browser session. XSS can be used to steal sensitive information, impersonate users, redirect victims or change the content displayed on a webpage.

More information about Cross-Site Scripting

Reference: OWASP Foundation - Cross Site Scripting (XSS)

Cross-Site Request Forgery (CSRF)

Image source: Imperva

Cross-Site Request Forgery tricks an authenticated user's browser into sending a request that the user did not intend. Because the browser may automatically include the user's session credentials, a vulnerable website can treat the forged request as legitimate. A successful CSRF attack can cause actions such as changing account details or performing transactions without the user's permission.

More information about Cross-Site Request Forgery

Reference: OWASP Foundation - Cross Site Request Forgery

Command Injection

Image source: Wikimedia Commons

Command injection occurs when unsafe user-controlled data is passed to an operating-system command interpreter. An attacker may add commands that are then executed by the server with the privileges of the vulnerable application. This type of attack is commonly associated with insufficient input validation and unsafe use of system commands.

More information about Command Injection

Reference: OWASP Foundation - Command Injection

Path Traversal

Image source: Spanning

Path traversal is an attack that attempts to access files and directories outside the location that a web application normally allows. An attacker may manipulate file paths using sequences such as ../ or by supplying absolute file paths. If successful, the attack may expose application source code, configuration files or sensitive operating-system files.

More information about Path Traversal

Reference: OWASP Foundation - Path Traversal

Server-Side Request Forgery (SSRF)

Image source: LinkedIn

Server-Side Request Forgery occurs when an attacker causes a server-side application to make requests to a location chosen or influenced by the attacker. Because the request originates from the server, it may be able to reach internal services that are not directly available from the Internet. A successful SSRF attack may expose sensitive information or allow interaction with internal systems.

More information about Server-Side Request Forgery

Reference: OWASP Foundation - Server Side Request Forgery

Clickjacking

Image source: Wikimedia Commons

Clickjacking uses hidden or deceptive webpage layers to trick a user into clicking something different from what they believe they are clicking. A legitimate page or control may be placed underneath another visible element so that the user's click is redirected. The attack can cause a victim to perform an unintended action on another website or application.

More information about Clickjacking

Reference: OWASP Foundation - Clickjacking

Session Hijacking

Image source: sectigostore

Session hijacking occurs when an attacker obtains or abuses a valid user's session identifier, which is commonly stored in a browser cookie. By presenting the stolen session information to a vulnerable application, the attacker may be treated as the legitimate user. This can allow access to the victim's authenticated session without requiring the victim's password.

More information about Session Hijacking

Reference: OWASP Foundation - Testing for Session Hijacking

Brute-Force Attack

Image source: The SSL Store

A brute-force attack repeatedly tries passwords or other credentials until a valid combination is discovered. Automated tools can perform large numbers of authentication attempts and may use dictionaries or commonly used passwords to improve efficiency. Weak passwords and inadequate protection against repeated login attempts increase the risk of this attack.

More information about Brute-Force Attacks

Reference: OWASP Foundation - Brute Force Attack

Denial-of-Service (DoS)

Image source: Spanning

A Denial-of-Service attack aims to make a website, application or server unavailable to legitimate users. An attacker may overwhelm the target with requests or exploit resource-handling weaknesses so that the system can no longer respond normally. The result can range from significant performance problems to complete loss of availability.

More information about Denial-of-Service

Reference: OWASP Foundation - Denial of Service
